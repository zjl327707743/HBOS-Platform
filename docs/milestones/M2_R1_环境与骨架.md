### 排障记录

1. **模块包名不匹配**：migrate 报 `ModuleNotFoundError: No module named 'hb_lims_app.hbos_lims'`。根因：Frappe 将模块名 "HBOS LIMS" 转换为包名 `hbos_lims`，业务包最初命名为 `hb_lims` 不匹配。已将业务包重命名为 `hbos_lims`（与 hb_attendance_app / hbos_attendance 先例一致）。
2. **Desktop Icon 背景色**：Frappe v16 的 `bg_color` 仅允许 `gray` / `blue`，`green` 报 ValidationError。已改为 `blue`。
3. **端口混淆**：`.env` 中 `HTTP_PORT=8080`（M0 期间曾改 8081，现已改回）；本机 8081 为 SENAITE 演示容器端口。HBOS Desk 地址为 `http://localhost:8080`，验证须带 `Host: frontend` 头。
4. **frontend 容器 assets 回归**：容器重建后 `/home/frappe/frappe-bench/assets/` 仅有镜像默认的 frappe / erpnext 软链接，hb_attendance_app 与 hb_lims_app 均缺失（M0-R3C-FIX 已知环境问题）。已在 frontend 容器补建两条软链接，并将此步骤记录为 M2 环境维护动作。

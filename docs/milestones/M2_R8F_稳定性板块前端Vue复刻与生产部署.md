## 5. 与设计方案的一致性

> **与设计方案 §3.1 的差异（Owner 2026-09-16 指示）**：设计方案 §3.1 曾把侧栏拆为
> 「稳定性工作台 / 考察管理 / 结果与报告 / 运行保障」4 个分组。Owner 反馈分组过多，
> 本轮**已合并为单个「稳定性管理」分组 7 入口**，与留样板块「留样管理」一个分组
> 承载全部入口的做法一致。视图、路由、页面内容均不受影响。

- **期限三层模型**（方案 §5.2）：计划台账与日期链抽屉并列展示
  `planned_due_date` / `effective_due_date` / `policy_latest_due_date`，
  抽屉内给出 `planned ≤ requested ≤ approved ≤ policy_latest` 校验说明。
- **结果版本与快照**（方案 §5.3）：结果页默认只展示当前生效结果，
  `is_current` / `current_result` 在文案上明确「由受控业务方法完成，原型只展示结果」。
- **延期为独立动作**（方案 §6.4）：申请与批准分列，申请中不改变有效截止日。
- **入箱超期不硬拦截**（方案 §6.3）：入箱抽屉提示「强制评估四件套」而非拒绝。
- **外推助手只给建议**（方案 §6.6）：`QA 判定` 为独立按钮，助手不写入有效期。
- **不重复造审计页**（方案 §3.1）：侧栏「合规审计日志」沿用既有 `/audit-log` 路由，
  视图内「审计」按钮只弹摘要抽屉。

## 3. 页面路径

Owner 复验路径：

1. 打开 `http://localhost:8081/app`。
2. 进入 `海滨考勤工作台`。
3. 点击 `导入考勤机导出表`。
4. 上传 Owner 本地 `.xlsx` 原始表格。
5. 点击 `识别并预览`，查看文件类型、日期范围、员工行数、日期列数和默认班次。
6. 点击 `确认导入`，查看新增打卡流水、跳过重复记录、新增考勤结果、已存在考勤结果、失败记录、自动考勤和兜底生成。
7. 跳转查看 `导入日志`、`打卡流水`、`考勤结果`。

## 文档定位

本文档是 M1 考勤一期的产品需求说明书（PRD），基于 `M1_考勤一期真实需求确认.md` 中的 5 轮访谈结论编写。本文档将业务需求转化为产品设计，不展开技术实现细节。

## 背景

新乡海滨当前考勤管理依赖纸质表和打卡机导出 Excel，每月末由人事手工汇总统计。M1 目标是构建一个可在本地 Demo 环境中运行的考勤管理系统，实现 Excel 导入、考勤结果生成、异常处理和月度汇总导出的完整闭环。

M1 是内部可演示版本 + 可给人事试用的本地 Demo，不是正式生产上线。

## 目标

1. 构建考勤工作台作为人事考勤管理的主入口
2. 支持从 Excel 导入脱敏考勤数据并生成考勤结果
3. 实现迟到、早退、缺卡、缺勤的自动识别
4. 完整覆盖员工→主管→人事的异常处理三级流程
5. 实现月度汇总报表与 Excel 导出
6. 支持飞书一键登录（M1 后段）
7. 为领导提供汇总 Demo 视图

## 用户角色

| 角色 | 核心需求 |
| --- | --- |
| 员工 | 查看个人考勤记录；提交补卡 / 异常说明；导出个人月报 |
| 部门主管 | 查看本部门考勤与异常；确认异常事实；审批补卡/请假/加班 |
| 人事 / 考勤管理员 | 员工与班次维护；导入打卡 Excel；运行考勤；处理异常；生成月报；导出 Excel；配置考勤规则；最终归档 |
| 领导 | 查看本月异常人数、迟到/缺卡次数、部门排名；查看月报 |
| 系统管理员 | 全量系统配置与权限维护 |

M1 暂定人事即为考勤管理员。

## 使用场景

### 场景 1：人事导入月度考勤数据

人事登录考勤工作台 → 进入导入页面 → 选择脱敏后的打卡流水 Excel 或月度汇总 Excel → 系统校验并导入 → 展示导入结果（成功/失败数）。

### 场景 2：员工查看个人考勤

员工通过飞书登录或浏览器访问 → 进入个人考勤视图 → 查看今日状态、本月记录、异常清单、请假/加班记录 → 如有迟到/缺卡等异常，可提交异常说明。

### 场景 3：主管确认部门异常

主管登录 → 进入本部门异常视图 → 查看异常员工列表和详情 → 逐条确认事实或驳回 → 提交给人事处理。

### 场景 4：人事处理异常与归档

人事登录 → 进入异常处理工作台 → 查看主管已确认的异常 → 修正数据 / 补卡处理 → 确认归档 → 生成月度汇总 → 导出 Excel。

### 场景 5：领导查看月度汇总

领导登录 → 进入汇总视图 → 查看本月关键指标 → 查看部门排名 → 导出或查看月报。

## 页面 / 入口设计

### 考勤工作台（Frappe Desk / Workspace）

- 各角色登录后的主入口
- 根据角色展示不同的快捷操作和数据卡片

### 员工个人考勤视图

- 今日考勤状态卡片（正常 / 迟到 / 早退 / 缺卡 / 缺勤）
- 本月考勤记录列表（按日期）
- 异常清单（迟到/早退/缺卡/缺勤标记）
- 请假记录列表
- 加班记录列表
- 「提交异常说明」入口
- 「导出本人月报」按钮

### 主管本部门异常视图

- 本部门异常员工列表
- 异常详情（哪一天、什么类型）
- 「确认事实」按钮
- 「驳回」按钮
- 异常处理历史

### 人事 / 考勤管理员处理入口

- 员工管理（查看 / 维护列表）
- 班次管理（维护白班/中班/夜班/行政班）
- 数据导入入口（打卡流水导入 + 月度汇总导入）
- 考勤运行入口
- 异常处理工作台
- 月度汇总报表
- 操作日志查询
- 考勤规则配置（迟到/早退/缺卡判定）

### 月度汇总报表

- 全公司 / 按部门的月度考勤汇总表
- 包含字段：员工姓名、部门、应出勤天数、实际出勤天数、迟到次数、早退次数、缺卡次数、缺勤天数、请假天数/小时、加班小时、节假日出勤、异常待确认数、最终考勤状态、备注
- 支持筛选：部门、日期范围
- 支持导出 Excel

### 领导汇总 Demo

- 关键指标卡片：本月异常人数、迟到总次数、缺卡总次数
- 部门排名表
- 支持查看和导出月报

## 考勤主流程

1. 人事 / 考勤管理员导入脱敏打卡 Excel
2. 系统生成或展示考勤结果
3. 系统自动识别迟到、早退、缺卡、缺勤
4. 员工查看自己的考勤结果
5. 对异常项，员工可提交考勤异常说明
6. 部门主管确认异常事实
7. 人事 / 考勤管理员最终处理并修正
8. 生成月度汇总
9. 导出 Excel 月报
10. 领导查看汇总 Demo

## 异常处理流程

```
员工发现异常 → 提交考勤异常说明（选择类型）
→ 部门主管确认事实（确认/驳回）
→ 人事 / 考勤管理员最终确认与数据处理
→ 所有操作留痕
```

异常说明类型：补卡、设备异常、公出/会议、班次错误、请假未同步、其他。

权限责任：

- 员工：提交说明
- 主管：确认事实
- 考勤管理员：修正数据
- 人事：最终归档

月度最终状态：正常 / 异常 / 已确认。

## 月度汇总与导出

- 月度汇总报表在 Frappe Desk 内以列表/表格形式展示
- 支持按部门筛选
- 支持导出为 Excel（格式兼容现有模板）
- 导出的 Excel 应包含月度汇总全部字段

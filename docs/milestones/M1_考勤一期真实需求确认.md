## 考勤规则

### 迟到

- 超过上班时间 0 分钟即算迟到。
- M1 不设置宽限期。

### 早退

- 早于下班时间 0 分钟即算早退。
- M1 不设置宽限期。

### 上班缺卡

- 上班缺卡 = 缺卡异常，不直接算缺勤。
- 员工可提交补卡说明。
- 主管确认事实。
- 人事 / 考勤管理员最终处理。

### 下班缺卡

- 下班缺卡 = 缺卡异常，不直接算早退或缺勤。
- 员工可提交说明。
- 主管确认。
- 人事 / 考勤管理员最终处理。

### 全天无打卡

判断顺序（严格按此顺序）：

```
先看是否请假
再看是否节假日 / 休息日
再看是否有排班
如果有排班且无请假、无打卡，则记为缺勤
```

### 请假

- M1 支持在 HRMS 中手动创建请假。
- M1 支持从 Excel 导入请假记录。
- 未来希望可以接入飞书请假。

请假换算：

- 半天请假 = 0.5 天 / 4 小时
- 全天请假 = 1 天 / 8 小时

### 加班

- 必须有加班审批才算正式加班。
- 仅靠超过工时或下班后打卡，不能自动认定为正式加班。

### 节假日出勤

- 节假日出勤 = 记录为节假日出勤，不自动转加班或调休。

### 临时调班

- M1 不做完整调班审批流。
- 由考勤管理员维护 Shift Assignment。
- 主管 / 人事确认调班事实。

### 考勤异常说明

M1 统一叫"考勤异常说明"。

类型字段：

- 补卡
- 设备异常
- 公出 / 会议
- 班次错误
- 请假未同步
- 其他

### 月度最终状态

- 正常
- 异常
- 已确认

### 操作留痕

M1 至少记录：

- 谁
- 什么时候
- 改了什么
- 修改原因
- 处理状态

## 数据来源与导入

### M1 数据策略

- M1 使用真实导出的考勤机 Excel，但必须脱敏。
- M1 使用真实组织架构。
- M1 做全公司结构模拟。
- M1 至少要有固定 Demo 数据集 + 可复现导入步骤，不一定做一键重置按钮。

注意：已确认使用真实组织架构。员工姓名是否脱敏需用户进一步确认。

### 班次

M1 必须支持的班次：

- 白班
- 中班
- 夜班
- 行政班

技术评估：夜班跨日期问题可能导致 Attendance 日期归属与人工理解不一致，需在技术设计中预留跨日处理方案，M1 优先用 Shift Type 原生跨夜配置验证。

### 现有 Excel 模板字段

当前模板包含以下字段：

- 姓名
- 工号
- 部门
- 请假时长（小时）
- 应出勤天数
- 实际出勤天数
- 计薪时长（小时）
- 迟到次数
- 早退次数
- 旷工天数
- 每日统计列，例如：
  - 周三 26-07-01
  - 周四 26-07-02
  - 周五 26-07-03

### 两类导入必须区分

```
原始打卡流水导入 ≠ 月度汇总 Excel 导入
```

- **原始打卡流水导入**：用于生成 Employee Checkin → Attendance。
- **月度汇总 Excel 导入**：用于对账、汇总展示、历史数据迁移、演示报表。

不得把月度汇总表错误当成原始打卡流水。

### 导入方式

- M1 先用 CSV / Excel 模板导入。
- 优先复用 HRMS Data Import。
- 如果原生不适合，再设计 HBOS 导入入口。
- 后续再做考勤机自动同步。

### 导入批次

- M1 技术方案必须设计导入批次。
- M1 实现上可以先不做复杂批次管理。
- 如果使用自定义导入入口，则必须保留导入批次记录。

技术评估：建议导入批次字段包括：

- 导入批次号
- 导入人
- 导入时间
- 来源文件名
- 总记录数
- 成功数
- 失败数
- 失败原因

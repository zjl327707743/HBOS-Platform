# M3 仓储库存数字化管理

项目名称：新乡海滨智能运营管理平台。

## 里程碑定位

M3 由 Owner 明确授权新开，目标是把仓库产品库存信息数字化，形成"产品—批次—货位"对应台账，并在此基础上支持批次查询、出库核销、效期预警、盘点导出、待检证与货位卡生成、货位二维码与手机扫码查询、入库拍照识别。

M3 与 M1（考勤）为并列里程碑，不替代、不阻塞 M1-FIX。

## 目标

1. 建立产品主数据与批次（批号、生产日期、有效日期）口径。
2. 建立货位编码体系，形成"产品—批次—货位"对应台账。
3. 支持按批号快速查询货位及数量。
4. 支持出库核销、效期预警、盘点导出。
5. 依据关键信息自动生成待检证、货位卡。
6. 生成货位二维码并支持手机扫码查询货位信息。
7. 支持入库拍照识别产品名称、批号、代码、日期，人工校对后入台账。

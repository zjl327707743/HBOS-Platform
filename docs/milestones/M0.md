# M0：工程启动与项目骨架

项目名称：新乡海滨智能运营管理平台。

## M0 目标

M0 的目标是完成工程启动、AI 上下文治理、基础架构决策记录、Frappe / ERPNext / Docker 最小环境方案设计，以及后续实际落地前的状态管理规范和 AI Skill 路由规则。

## M0 范围

- 建立项目根目录文档与 AI 协作入口。
- 建立项目状态、当前里程碑和阅读规则。
- 建立基础 ADR。
- 设计 Frappe / ERPNext / Docker 最小本地环境方案。
- 建立里程碑规划和状态同步机制。
- 建立 AI Skill 路由和已确认 / 候选 skill 边界。

## M0 不做事项

- 除用户明确批准的 M0-R3A 最小 Docker 环境落地外，不安装、运行或生成 Frappe / ERPNext。
- 不创建 Frappe bench。
- 不创建任何海滨自定义 Frappe App。
- 不创建 `hb_core_app`、`hb_attendance_app`、`hb_feishu_app`。
- 不提交真实 `.env` 或真实密钥。
- 不开发考勤业务。
- 不接入飞书真实写入。
- 不实现 Vue/React 驾驶舱。
- 不引入外部源码。

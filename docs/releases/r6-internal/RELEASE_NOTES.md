# HBOS R6 团队内部集成验收版说明（草稿）

状态：`GUIDE_PREPARED`，尚未合并/发布最终固定版本。仓库 `zjl327707743/HBOS-Platform`，产品分支 `feature/hbos-portal-product`；最终完整 SHA、tree、获准标签和包摘要以外部 `RELEASE_MANIFEST.json` 为准。

本版把现有六 PR 的登录后体验和必要后端合同收敛为同一内部验收版本：个人中心、员工管理、部门按应用的默认权限、个人例外、角色与权限发布/撤权、变更记录和账号安全操作的收据恢复。保留 Owner 已通过的页面与设计，保留已合并飞书登录，不新增业务功能。

与旧 RC1 的主要差异：

- 管理入口、员工资料和权限状态解释按已确认 R6 体验统一，员工业务权限由服务端与对象范围控制。
- 部门默认与个人安排分开表达；管理型部门默认必须明确部门/公司范围并逐人确认，不隐含授权全部成员。
- 安全写入采用数据库持久收据。相同请求丢应答可核对、重放或明确封存未知请求；本轮在原 #67 补验 ABORTED 竞争与旧尝试隔离，具体通过结论见最终证据。
- 请求前只读重试、具名 HR 的精确原生 User Permission 兼容，以及基线知识库路由/导航随同集成。

新 Site 初始没有公司、员工、已发布角色或真实外部配置。按团队指南用合成数据完成管理员引导；角色初始化只创建草稿，发布、委派、部门默认、个人安排和逐人确认均为显式步骤。外部同步/AI出站/飞书自动开户不自动开启。

升级必须先验证一致性备份及隔离恢复，再安装准确 M 的运行与静态资产，连续执行两次 migrate。收据模型及唯一索引、专用站点签名 key、部门逐人准入模型都属于升级范围。#68 与 #63 必须作为同批完整源码交付，不部署中间态；不能只替换前端作为完整回退。

共享合成入口：`http://pr61-synth.localhost:18191/hbos/login`。每位成员自行配置隔离本地凭据，不共享 Owner 的 Administrator、飞书绑定或 Site 配置。

本版范围为团队内部拉取、安装、开发和验收。生产、main、正式生产 Release、真实员工全员启用，以及其他业务 App 的完整授权接入和真实数据分发不在本版许可内。已知未测项及工具限制见 `KNOWN_LIMITATIONS.md`；完成干净环境实际复现前 `TEAM_PULL_READY=NO`。

# 仓库工作台操作手册

> **写给谁**：仓库操作人员。不需要懂 ERPNext，照着做即可。
> **对应版本**：M3-R6（2026-09-23）。本文只讲「怎么操作」，不讲设计原理。

---

## 一、从哪进去

浏览器打开 `http://192.168.0.179:8080`，登录后：

- **推荐**：在「桌面」上找蓝色 **`仓库工作台`** 图标（图标是几个盒子），点进去；
- 或者直接在地址栏敲：`http://192.168.0.179:8080/app/仓库工作台`

进去之后，**左侧一整条**就是本工作台自己的菜单，按用途分了 5 组（见下）。
**从这里点任何一条，都不会跳到别处去。**

> ⚠ **不要**去点左侧最下面的「库存」模块——那是 ERPNext 原装菜单，
> 里面**没有**本工作台的条目，进了容易绕不出来。要做的事本文都有。

## 三、先搞清楚：一张库存单是什么

点「**库存单据（入库/出库/移库）**」，看到的是一张**清单**（历史上所有的单子）。
右上角有「**+ 添加物料移动**」按钮，点它就是**新开一张单**。

一张库存单 = 表头（公司、类型、日期）+ 明细表（**每一行 = 一种物料**）。
按「**移动类型**」分为三类，用哪一类决定了后面要填哪几个仓库格：

| 移动类型（系统里显示的名字） | 干什么 | 要填的仓库格 |
| --- | --- | --- |
| **其他入库** | **入库**：东西进仓库 | **收料仓**（货位） |
| **其他出库** | **出库**：东西出仓库 | **发料仓**（货位） |
| **直接调拨** | **移库**：仓库内换货位 | **发料仓 + 收料仓** 都要填 |

> ⚠ **「其他入库」这个名字很容易看错**——它是 ERPNext 的固定叫法，
> 不是"杂项入库/其他乱七八糟的入库"，**正常的入库就是它**。
> （拍照识别生成的草稿，移动类型也是「其他入库」。）
>
> 同理「其他出库」就是**正常出库**（领用、报废等），不是杂项。

## 四、怎么开一张入库单（手工）

**入库前请先确认：这个批号在系统里建过没有。**
所有物料都开了批号管理，所以**批号必须先存在**。

### 第 1 步：建批次（没有才需要）

左侧「**批次**」→ 右上「+ 添加批号」→ 填：

| 字段 | 填什么 | 必须吗 |
| --- | --- | --- |
| **批号** | 标签上印的批号（如 `B2607519`） | ✅ 必填 |
| **物料** | 选物料代码，例如 `13000892` | ✅ 必填 |
| **HBOS 来源类型** | 自产 / 外购 | ✅ 请务必选对 |
| 生产日期 | 标签上的生产日期 | 建议填 |
| 有效期 | 标签上的有效期 | 建议填 |
| **HBOS 放行状态** | 默认「待检」 | 入库保持「待检」 |
| HBOS 合格证编号 / 附件 | 出库前才需要 | 入库可留空 |

> **为什么「来源类型」重要**：它决定打印哪种货位卡（自产版 / 外购版）。

### 第 2 步：开入库单

左侧「**库存单据（入库/出库/移库）**」→ 右上「**+ 添加物料移动**」→ 按下表填：

| 表格 | 字段 | 填什么 |
| --- | --- | --- |
| 表头 | **移动类型** | 选「**其他入库**」 |
| 表头 | **公司** | 自动带出，别动 |
| 明细第 1 行 | **物料号** | 选物料代码 |
| 明细第 1 行 | **数量** | 本次入库数量（如 `3`） |
| 明细第 1 行 | **单位** | 一般自动带出（`Kg`），别乱改 |
| 明细第 1 行 | **收料仓** | **选具体货位**，如 `16-03-211 - HB` |

**只有这几格要填，其余别动。**

> ⚠ **「批号」那一列默认应该就在**。如果没看到，把明细行展开（点行末箭头 `>`），
> 勾上「**启用明细行批号与序列号字段**」，批号列就会出现。
> 不勾的话系统会改用「序列号与批号」的弹窗选择框——那条路也能走，
> 但要多点好几下，**而且容易选错**，建议就用批号列。

> ⚠ **「收料仓」要选到"货位"这一层**（形如 `16-03-211 - HB`），
> **不要选「第一层 - HB」这种分组**——系统会报「是分组节点，不能直接存货」。

### 第 3 步：保存并提交

1. 右上「**保存**」→ 单据状态变「草稿」；
2. 核对无误后点右上「**提交**」；
3. **提交成功后系统自动做一件事**：把该批次的「**待检证 + 货位卡**」
   生成一个 PDF，挂到**批次的附件**里（见第六节）。

## 五、怎么开一张出库单（⚠ 有前置条件）

**出库有硬门槛：批次必须已经 QA 放行、且填了合格证编号，否则提交会被系统拦住。**

### 第 1 步：先在批次上录放行（QA 给完之后）

左侧「**批次**」→ 找到对应批号 → 填：

| 字段 | 填什么 |
| --- | --- |
| **HBOS 放行状态** | 改成「**已放行**」 |
| HBOS 放行日期 | QA 放行日期 |
| **HBOS 合格证编号** | QA 给的合格证号（**必填，留空一样被拦**） |
| HBOS 合格证附件 | 有就传，没有也行 |

### 第 2 步：开出库单

「**库存单据**」→「+ 添加物料移动」：

| 字段 | 填什么 |
| --- | --- |
| 移动类型 | 「**其他出库**」 |
| 明细：物料号 / 数量 / 单位 | 同入库 |
| 明细：**发料仓** | 从哪个货位出（**批号同理需要勾选才看得到**） |

提交时如果报「**出库放行校验未通过**」，就回第 1 步把放行状态和合格证编号补上。

> **出库批次默认按先进先出（FIFO）自动挑**，不用手选批次。
> 领料时如果必须指定批次，在明细行里手工选。

---

## 六、怎么开一张移库单（货位变更）

「**库存单据**」→「+ 添加物料移动」：

| 字段 | 填什么 |
| --- | --- |
| 移动类型 | 「**直接调拨**」 |
| 明细：**发料仓** | 原来的货位 |
| 明细：**收料仓** | 要搬去的货位 |
| 明细：物料号 / 数量 / 批号 | 同前 |

**移库不查放行**（属于库内流转），所以东西没放行也能挪。

---

## 七、入库之后怎么拿「待检证 + 货位卡」

**入库单提交成功后，系统自动生成**，不用手动做。

| 项 | 说明 |
| --- | --- |
| 内容 | 「**待检证**（75×110mm 小标签）+ **货位卡**（A4）」合成**一个 PDF** |
| 在哪 | 打开对应的 **`批次`** → 右侧「附件」区，文件名形如 `HBOS-<批号>-待检证+货位卡.pdf` |
| 怎么用 | 点开下载 / 直接打印 |

**批次页上还有个「重新生成货位卡 / 待检证」按钮**，两种情况用：
- 自动生成**失败**了（提交时会弹提示告诉你是哪几个批次）；
- 数据后来**变了**（比如 QA 补了放行、又出了几次货），需要重出一份。

> 重新生成会**替换上一次自动生成的那份**，不会越堆越多，
> 也**不会动你自己手工传上去的附件**。

## 八、入库拍照识别（第一节那条，推荐用它）

手工录入容易抄错，**能用拍照就用拍照**。

左侧「**入库拍照识别**」，四步：

| 步 | 做什么 |
| --- | --- |
| **① 标签照片** | 手机拍 / 电脑选；照片只在内网处理 |
| **② 识别** | 选来源类型 → 点「开始识别」（单张约 8 秒） |
| **③ 人工校对** | **橙色高亮 = 必须核对**。页面把标签上要印的信息**全列在一处**：识别到的已预填、没读到的留空，照标签直接填 |
| **④ 生成草稿** | 选货位、填数量 → 点「生成草稿（不直接入账）」 |

然后点「**打开草稿**」→ 核对 → **提交**。
提交后同样会自动生成货位卡与待检证。

> **识别结果不直接入账**。识别只负责"读"，**人负责"定"**——
> 校对那一步是强制的，别跳过。

---

## 九、提交之后会看到什么

把拍照识别的草稿提交后，会弹一个框问你下一步去哪：

- **打开该批次（取货位卡 / 待检证）** ← 一般点这个
- 继续识别下一张

## 十、常见提示与处理

| 屏幕上看到 | 什么意思 | 怎么办 |
| --- | --- | --- |
| 「**以下批次未取得 QA 放行手续或合格证，不可出库**」 | 该批次没放行 | 按第五节第 1 步，在批次上补放行状态 + 合格证编号 |
| 「**XXX 是库位 / 层等分组节点，不能直接存货**」 | 货位选粗了 | 选到具体货位，如 `16-03-207 - HB` |
| 「**物料未建档**」/「物料代码 XXX 尚未建档」 | 这个物料还没进物料主数据 | 核对代码是否取错；确实没有就找 IT / 主数据管理员建 |
| 「**物料建档不完整**」/「不满足入库要求：未勾选「有批号」」 | 物料上少勾了开关 | 到物料主数据补勾「**有批号**」（本流程必填）、「**维护库存**」，且不能是「已停用」 |
| 「**找不到批号**」 | 批号还没建 | 先在「批次」里建（第四节第 1 步） |
| 明细里**找不到「批号」那一列** | 该行没启用批号字段 | 展开明细行，勾「启用明细行批号与序列号字段」 |
| 「**识别服务当前不可用**」 | 识别服务没开 | 找 IT；此时手工开入库单（第四节）也能用 |

**其他情况拿不准时：不要硬提交，先截图问。** 提交后改起来麻烦。

---

## 十一、三条纪律

1. **识别结果必须人工核对再提交**——AI 只负责读，人负责定。
2. **出库前 QA 放行手续必须齐**（放行状态 + 合格证编号），这是硬规则、系统会拦。
3. **不确定的不要硬试**。库存单提交会影响账面库存，比多问一句成本高得多。

## 十二、本文没写的（已知边界）

- **从「库存」原生模块或顶部搜索框自己进去**——那条路不归本工作台管，
  看到的仍是 ERPNext 原装界面，左侧菜单会换掉。**建议始终从工作台进。**
- **打印的货位卡流水行是手写区**（日期/去向/领料人/复核人等），
  系统不预填，打印出来手写即可。

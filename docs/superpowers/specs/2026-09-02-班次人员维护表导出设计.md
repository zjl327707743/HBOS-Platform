# 班次人员维护表导出设计文档

> 日期：2026-09-02
> 项目：新乡海滨智能运营管理平台
> 里程碑：M1-FIX-B5（考勤工作台增强）
> 状态：已获 Owner 逐节批准（文件结构 / 主表形态 / 行内列姓名 / 绑定+名单推导 / 行集 / 班次取值 / 豁免处置 / 特殊班次范围 / 三个设计小节）

---

## 一、目标

在「规则看板」新增「导出班次人员维护表」入口，导出长期可维护的 xlsx 档案：主表「部门-班次-人员」覆盖全部在职员工归属，补充豁免人员 / 特殊班次 / 行政班名单 sheet。

## 二、用户决策记录

| 决策点 | 结论 |
|---|---|
| 文件结构 | 主表 + 多名单 sheet |
| 主表形态 | 长表：部门 + 班次逐行 |
| 人员展示 | 主表行内列姓名 |
| 人员来源 | 绑定 + 名单推导 |
| 行集范围 | 仅有人的「部门 × 班次体系」组合 |
| 班次取值 | 按班次体系分组 |
| 豁免处置 | 豁免只列在豁免 sheet，不进主表 |
| 特殊班次范围 | 无菌倒班 / 四班次 / 安全倒班 / 食堂 四类全放 |

## 三、人员归行规则（每人唯一一行）

| 优先级 | 条件 | 归入班次体系 / 去向 |
|---|---|---|
| 0 | 豁免名单 EXEMPT_NUMS | **不进主表**，只进「豁免人员」sheet |
| 1 | 绑定班次规则（HBOS Employee Shift 主班次 / hbos_fixed_shift） | 该规则班次类型 |
| 2 | 无菌倒班 SPECIAL_SHIFT_NUMS | 无菌倒班 |
| 3 | 四班次 FOUR_SHIFT_NUMS | 四班次倒班 |
| 4 | 行政班 ADMIN_NUMS | 行政班 |
| 5 | 安全倒班 SAFETY_NUMS | 安全倒班 |
| 6 | 食堂 FOOD_NUMS | 食堂 |
| 7 | 其余在职员工 | 通用倒班 |

- 豁免优先级最高，命中豁免即不进主表。
- 绑定班次优先于名单（绑定了具体规则的人按规则班次归行，不受名单影响）。多绑定取 `is_primary=1` 的主班次；无主班次取第一条绑定；否则取 `hbos_fixed_shift`。
- 部门列取员工 HRMS 真实部门（非规则表部门）。

## 四、导出文件

**文件名**：`HBOS班次人员维护表_YYYYMMDD.xlsx`

| Sheet | 内容 | 列 |
|---|---|---|
| **部门-班次-人员**（主表） | 有人的「部门×班次体系」组合行 | 序号 / 部门 / 班次 / 上下班时间 / 迟到起算 / 人数 / 人员姓名 / 备注 |
| **豁免人员** | EXEMPT_NUMS 在职人员 | 工号 / 姓名 / 部门 / 原因（名单注释） |
| **特殊班次** | 四类特殊倒班人员（分小类区块） | 小类 / 工号 / 姓名 / 部门 |
| **行政班名单** | ADMIN_NUMS 在职人员 | 工号 / 姓名 / 部门 |
| **说明** | 口径与数据日期 | — |

- 行集：仅实际有人的「部门 × 班次体系」组合。豁免不进主表。
- 上下班时间：部门专属生效规则 → 全局「全部部门-HD」同类型 → 内置默认班次；特殊体系填「08:30-20:30 / 20:30-08:30（轮）」等描述。
- 姓名列统一「姓名（工号）」；未建档/离职工号只以工号出现。
- 特殊班次 sheet 覆盖：无菌倒班（SPECIAL_SHIFT_NUMS，59人）、四班次（FOUR_SHIFT_NUMS，9人）、安全倒班（SAFETY_NUMS，15人）、食堂（FOOD_NUMS，7人）。

## 五、触发入口与架构

规则看板顶部新增「导出班次人员维护表」按钮：

```
点按钮 → frappe.call(export_shift_roster)   @frappe.whitelist()
  → 读在职 Employee + 名单常量 + 绑定 + 生效规则 + 内置班次
  → openpyxl 生成 5-sheet xlsx
  → 存 Frappe File → 返回 file_url → 前端 window.open 下载
```

- 后端独立模块 `apps/hb_attendance_app/hb_attendance_app/hbos_attendance/roster_export.py`，复用现有 `report/月度考勤汇总/export.py` 的 openpyxl 样式模式（微软雅黑、表头底色、冻结、列宽）。
- 前端在 `hbos_shift_management.js` 规则看板渲染区顶部加按钮。

## 六、错误处理

- 无在职员工 / openpyxl 缺失 → `frappe.throw` 中文提示。
- 名单未建档（`HB-` 前缀）或离职 → 不报错，仅工号形式出现在对应名单 sheet，不进主表。
- 一人同时命中豁免 + 特殊班次 → 豁免优先；全流程姓名去重防一人双行。
- 导出只读，不触发 `regenerate_attendance`，不改数据库。

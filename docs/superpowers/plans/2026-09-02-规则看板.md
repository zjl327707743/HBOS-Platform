> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在「班次管理」页（hbos-shift-management）新增「规则看板」Tab，把三类班次判定规则（规则表记录 / 内置默认班次 / 名单与配对参数）可视化展示。

**Architecture:** 后端新增纯模块 `rules_board.py`（无 Frappe 依赖，静态数据全部 import 现有常量，供离线测试），在 `shift_management_data.py` 新增 `get_rules_board()` 白名单端点聚合规则记录 + 静态数据。前端 JS 改为页顶 Tab 结构，「班次设置」Tab 原样保留，「规则看板」Tab 渲染 5 个分区。名单常量从 `api.py` 抽到纯模块 `rule_lists.py`（api.py 保持 re-export，所有现有 import 不变）。

**Tech Stack:** Frappe Page + Python（whitelist 端点）、JavaScript（jQuery）、`unittest`（离线测试，无 Frappe 运行态）。

## Global Constraints

- **测试运行方式**（仓库既定）：`cd apps/hb_attendance_app && PYTHONPATH=. python3 -m unittest discover -s tests`。测试环境**没有** frappe（`import frappe` 失败），所有测试只能 import 纯模块（不含 `import frappe` 的模块）或用文件内容 / AST 校验。

- **Git commit 消息使用中文**，可保留 `feat`/`docs`/`refactor` 前缀（conventional commit），冒号后描述用中文。

```python
@frappe.whitelist()
def get_rules_board():
    """规则看板数据：规则记录（含绑定人数）+ 内置班次 + 名单 + 配对参数 + 判定优先级。

    只读端点，不触发考勤生成、不改数据库。各数据源独立 try/except，
    任一失败只空该分组并记录到 errors，不整体抛错。
    """
    from hb_attendance_app.hbos_attendance import rules_board as rb

    out = {
        "rules": [],
        "builtin_shifts": [],
        "lists": [],
        "pairing_params": [],
        "priority_chain": [],
    }
    errors = {}

    # 1. 规则记录（含实时绑定人数：HBOS Employee Shift 多绑定 + Employee.hbos_fixed_shift 单绑定）
    try:
        rules = [_fmt_rule(r) for r in frappe.db.get_all(
            "HBOS Shift Rule",
            fields=["name", "rule_name", "department", "shift_type",
                    "start_time", "end_time", "late_after", "min_hours",
                    "effective_from", "status"],
            order_by="department, start_time",
        )]
        count_map = {}
        for r in frappe.db.sql(
            "SELECT shift_rule, COUNT(*) c FROM `tabHBOS Employee Shift` GROUP BY shift_rule",
            as_dict=True,
        ):
            count_map[r.shift_rule] = r.c
        for e in frappe.db.get_all(
            "Employee", fields=["hbos_fixed_shift"],
            filters={"hbos_fixed_shift": ["is", "set"]},
        ):
            count_map[e.hbos_fixed_shift] = count_map.get(e.hbos_fixed_shift, 0) + 1
        for r in rules:
            r["assigned_count"] = count_map.get(r["name"], 0)
        out["rules"] = rules
    except Exception as e:
        errors["rules"] = str(e)

    # 2-5. 静态数据（纯函数，见 rules_board.py）
    for key, builder in (
        ("builtin_shifts", rb.builtin_shifts),
        ("lists", rb.list_groups),
        ("pairing_params", rb.pairing_params),
        ("priority_chain", rb.priority_chain),
    ):
        try:
            out[key] = builder()
        except Exception as e:
            errors[key] = str(e)

    if errors:
        out["errors"] = errors
    return out
```

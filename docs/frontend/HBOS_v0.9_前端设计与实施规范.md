## 3. 品牌、视觉与布局强制要求

- 对用户的正式名称为**海滨智能工作平台**；HBOS作为英文标识。不得因此改写企业法定名称、历史单据或服务标识。
- 保留已接受蓝紫/蓝/青/水绿氛围、明确的玻璃层次。正文必须可读，必要操作区域不以透明度牺牲对比；业务高密度录入采用稳定低强度表面，不能把持续粒子推广到全部应用。
- 企业、HBOS、飞书使用来源明确的原资产，保持比例、透明边缘与可访问名称。低清企业图不得强行放大或自行重绘商标；原图尺寸、显示框和回退见第3章。
- 布局用容器和网格对齐，而非逐页负margin补丁。标题、面板、操作栏、目录和主体遵守同一对齐线；窄屏重排。允许长名称换行，flex/grid子项合理设置min-width:0，不用缩小关键字号掩盖溢出。
- 列表必须能到最后一项，浮层正文和底部动作可触达；明确由页面、侧栏或弹窗哪个容器负责滚动，避免无必要的嵌套滚动。不能使用遮挡底部的固定高度修饰对齐。
- 具体断点、尺寸和局部例外按第4–6章；不能用两档通用断点覆盖所有认证/管理布局。

## 5. 组件、交互和状态（必须）

- 默认少用装饰箭头。导航用明确文字和当前项；折叠只在有展开含义时使用，保留aria-expanded/controls。管理中心渐进展开，不平铺全部高级功能。
- Button/Field/Select/Dialog/Drawer/DataState逐一覆盖默认、hover、focus、disabled、loading及错误；一个任务区一个主动作，忙碌防重入并保持尺寸。图标按钮必须有名称。
- 自定义下拉优先采用现有组件库的可靠受控组件；支持禁用项跳过、键盘选择、IME、Escape、回焦点和滚动边界。原型目录增强存在未实现项，不能照搬当作完成。
- 组合输入只保留一个清楚的焦点边框，不移除键盘焦点。浮层隔离背景、提供名称、合理初始焦点、焦点循环与返回；处理嵌套浮层和卸载。
- loading、empty、筛选无匹配、error、forbidden、stale、unknown分别表达。未知写入结果先按请求标识查询，不盲目重发。失败保留输入，错误关联字段，关键错误不只toast。
- 表单未改/已改/提交中/已确认/失败/未知分开；取消、返回、刷新、重复点击、超时、旧请求晚返回均须测试。模拟成功不能出现在生产服务未确认时。
- 数字按业务口径、单位、时区格式化并对齐；批量操作明确范围，筛选变化不能静默扩大选择；长文本/空值/缺权限不能挤压唯一动作。

## 6. 全平台用户文案合同

所有新改页面及其标题、菜单、按钮、说明、占位符、校验、通知、空态、错误、加载、成功、确认弹窗、无障碍名称与登录页都必须审查，不能只改首页。

写法：说明“这是什么/对我有何影响/下一步怎么做”。面向员工用自然中文，内部编号放详情供定位；禁止裸露组件名、DTO、状态枚举、Gate等实现术语作为主要解释。无法确认的结果明确说“暂时无法确认”，不写“完成”。不得删除安全含义来换取简短。

| 不采用 | 推荐表达（按真实业务状态调整） |
| --- | --- |
| 操作成功（未区分） | 已保存草稿，尚未生效 / 已发布所选角色配置 |
| 无数据（读取失败） | 暂时无法加载，请重试；已填写的内容会保留 |
| 再试一次（写入未知） | 暂时无法确认结果，请先查询上次操作 |
| 权限异常 | 你暂时无权使用此功能；按实际流程给申请或返回入口 |
| 邮件已送达（只有发送收据） | 恢复邮件已发送，请检查收件箱 |
| 全部停用（仅暂停一个应用） | 暂停此账号的〔应用名称〕访问 |

实施必须建立文案清单：路由/组件/状态/旧文案/新文案/权限含义/来源/验收截图。统一术语（员工档案、登录账号、应用角色、部门默认、个人例外、保存草稿、发布生效、查询上次结果），不改变术语所对应的业务对象。

## 7. 登录与安全边界

登录简洁居中、清楚的品牌和单一主操作；飞书优先、密码按需展开，使用飞书图标，授权等待与正在处理的动画分开，不预先显示“授权完成”。切换/取消不能留下过期倒计时、重复操作或失焦。

员工档案不等于账号，不按姓名自动认领；不安排角色、暂停应用、停用账号分开；草稿不生效；部门默认不覆盖个人例外；MFA/恢复/账号交接遵守既有服务合同。凭据不得写日志/前端存储。所有真正权限由后端决定。已有安全功能不能被演示逻辑降级。

## 8. 动效、可访问性与性能

保留默认开启的鼠标光晕、粒子、背景浮动、首页扫光和登录轻动效，主顶栏不放独立动效开关。尊重系统reduced-motion，粗指针不做鼠标轨迹，后台页暂停无必要动画，卸载释放监听/观察器/rAF。装饰pointer-events:none，不阻挡文字、点击或焦点。

原型最大60粒子、35ms生成节流、DPR封顶2及基于dt衰减是复现参考，不承诺60fps。动效不能假扮业务进度/健康状态。不新增应用拖排；若以后新增，需键盘及非拖动替代、取消/撤销和保存失败回滚。

生产验收目标WCAG 2.2 AA：普通文字4.5:1、大字3:1、必要控件3:1，按玻璃合成最差点测量；200%文字缩放、320px等效重排、可见焦点不遮挡、键盘和读屏。HBOS建议44×44命中区域，不把它混称WCAG AA最低24px规则。原型存在小目标/小字/下拉IME等待改项，必须登记并修复或经审查说明，不能宣称已全量符合。

# M2-R6A：样品登记动态表单设计方案与提示词

项目名称：新乡海滨智能运营管理平台。

## 轮次状态

状态：REVIEWING（等待 Owner 审查；未进入 Vue 实现改动）。本方案为 M2-R6A 第 2 版，按 Owner 反馈改为「下拉选择样品类型 + 每种类型一张完整表单」。

## 需求

- 在 `/hbos-lims/samples` 的样品登记页，将「样品类型」与「检验优先级」固定为始终可见的决策条。
- 两个字段均使用下拉列表（select）选择，不使用标签组 / 分段控件。
- 每个样品类型分别对应一张完整表单，不再拆「通用样品信息」和「类型专属信息」。
- 通过下拉切换样品类型后，整张表单替换为该类型专属表单，质量标准、检验项目快照与留样规则同步联动。
- 演示数据一律使用 `TEST-HBOS-M2-*` 前缀，不录入真实样品 / 人员 / 检测数据。

## 设计方案

### 1. 固定决策条（下拉选择）

- 位于表单顶部，使用 `position: sticky` 固定显示，滚动长表单时始终可见。
- 左侧为「样品类型」下拉框，右侧为「检验优先级」下拉框。
- 下拉框下方显示简短提示，例如「选择类型后，整张表单切换为该类型专属表单」。
- 决策条内显示当前模板名称，例如「当前模板 成品检验」，减少切换后的迷失感。

### 2. 每种类型一张完整表单

| 样品类型 | 表单核心字段 |
| --- | --- |
| 成品 | 物料编码、物料名称、批号、规格型号、包装规格、生产日期、有效期至、留样数量、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 原料 | 物料编码、物料名称、供应商、供应商批号、批号、到货日期、留样数量、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 中间体 | 物料编码、物料名称、工序名称、中间体批号、生产日期、留样数量、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 包装材料 | 物料编码、物料名称、供应商、材质/规格、供应商批号、抽样数量、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 工艺用水 | 水系统名称、取样点、取样时间、取样人、监测项目组、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 水 | 水系统名称、取样点、取样时间、取样人、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 环境样品 | 环境区域、取样点、取样时间、取样人、监测频次、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 稳定性样品 | 物料编码、物料名称、批号、考察条件、考察阶段、考察时间点、考察开始日期、下一时间点、留样数量、质量标准、检验时限、储存条件、默认留样天数、样品说明 |
| 清洁验证样品 | 清洁设备、验证批次、取样点、取样人、取样时间、清洁剂、验证阶段、样品来源、质量标准、检验时限、储存条件、默认留样天数、样品说明 |

### 3. 联动规则

- 切换「样品类型」下拉后，整张表单重新渲染为该类型表单，所有字段随模板变化。
- 右侧「已匹配质量标准」和「检验项目快照」随类型同步更新。
- 「检验优先级」只影响排程与检验时限，不改变表单字段。
- 切换类型时带轻量淡入动画，避免整页跳动。
- 登记成功后关键字段锁定，修改必须走修订流程。

### 4. 视觉与响应式

- 保持制药实验室的洁净、严谨风格：深青侧栏、米白背景、绿色主操作、状态语义清晰的 Pill。
- 桌面端为左右两栏：左侧固定决策条 + 完整类型表单，右侧质量标准匹配与检验项目快照。
- 平板与手机端决策条取消 sticky，左右两栏改为单列，下拉框占满整行。

## 设计提示词

```text
你是资深制药行业 UI/UX 设计师。请为 HBOS LIMS 样品登记页设计一个「固定决策条 + 每种样品类型一张完整表单」的界面，要求：

1. 页面顶部是样品登记标题和「保存草稿 / 登记样品」操作按钮。
2. 表单顶部是一条始终可见的「样品决策条」，左侧为「样品类型」下拉列表（成品、原料、中间体、包装材料、工艺用水、水、环境样品、稳定性样品、清洁验证样品），右侧为「检验优先级」下拉列表（常规、加急、特急）；决策条需有「固定显示」标识和当前模板提示。
3. 决策条下方只有一张完整表单：切换样品类型下拉后，整张表单替换为该类型专属表单；不要出现「通用样品信息」和「类型专属信息」的分区，也不要保留跨类型共用字段区。
4. 右侧信息栏展示「已匹配质量标准」卡片与「检验项目快照」表格，内容随类型变化。
5. 每种类型表单字段需完整覆盖该类型的登记信息，例如成品包含物料编码/物料名称/批号/规格型号/包装规格/生产日期/有效期至/留样数量/样品来源/质量标准/检验时限/储存条件/默认留样天数/样品说明；原料包含供应商/供应商批号/到货日期；环境样品包含环境区域/取样点/监测频次；稳定性样品包含考察条件/考察阶段/考察时间点。
6. 视觉风格要体现 GMP 制药实验室的专业感：洁净、严谨、高信息密度，不要营销式大图；主色为深青色（#0c7c6a），背景为浅灰绿，状态用 Pill 语义色表达；卡片圆角不超过 8px。
7. 桌面端为左右两栏布局，平板和手机端为单列并取消 sticky；所有文本不能溢出容器。
8. 设计需覆盖默认「成品」类型，并再给出切换「环境样品」或「稳定性样品」后的完整表单状态示意。
9. 输出建议同时提供：高保真页面图、下拉切换交互说明、响应式断点说明和组件清单。
```

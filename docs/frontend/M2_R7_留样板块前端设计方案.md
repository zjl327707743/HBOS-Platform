# M2-R7 留样板块前端设计方案（原型 / 视觉方案阶段）

项目名称：新乡海滨智能运营管理平台（HBOS）。

轮次定位：M2-R7D 的「原型先行」阶段。本方案基于 M2-R7 rev6 已批准业务口径、角色方案 B+SoD、分支策略 b，给出留样板块独立前端的可执行设计方案；配套交互式设计稿为 `docs/frontend/M2_R7_留样板块前端原型.html`，供 Owner 确认。

状态：DESIGN 已交付并被 Owner 采纳（2026-09-08 确认进入 Vue 复刻并授权同步生产 `/hbos-lims`，当前 DEPLOYED；前端落地记录见 `docs/milestones/M2_R7D_留样板块前端设计.md`）。

## 一、输入与现状

- 业务依据：`docs/milestones/M2_R7_留样管理板块开发方案.md` rev6（5 主 DocType + 1 子表、三状态机、角色矩阵、SoD、四步锁协议、审计事件枚举）。
- 前端规范：`docs/frontend/FRONTEND_IMPLEMENTATION_GUIDE.md`（原型先行 → Owner 审查 → Vue 复刻 → 功能接入）。
- 现有前端基线：`frontend/hbos-lims-web`，Vue 3 + Vite + TypeScript + Pinia + Vue Router + Ant Design Vue + ECharts + SCSS Token。
- 现有留样页面：`RetentionView.vue`（留样登记与台账）、`RetentionProductView.vue`（留样产品）已提交，作为复刻基线；本轮不改动 Vue 工程。
- Skill 说明：当前环境未安装 `frontend-design` skill，按项目规则执行等价人工设计，不虚构技能能力。

## 二、设计目标与边界

目标：

1. 覆盖留样全生命周期：产品主数据、登记入库、库存台账、观察计划、使用申请、处理销毁。
2. 同时满足 Analyst、Reviewer/QA、Manager 三类使用视角，操作按钮按角色矩阵显隐。
3. 库存展示统一使用「结存 / 预占 / 可用量」，其中可用量为派生量，前端只展示不回写。
4. 所有写操作仅对接 `retention_service` whitelist 方法，前端只负责表单、确认、错误呈现。
5. 保持与已上线 R6C/R6D 页面一致的视觉语言与组件风格。

边界：

- 不修改 `frontend/hbos-lims-web/` 业务代码；不创建 Vue 页面。
- 不创建 DocType、不写 Python 业务方法。
- 不接真实 API，API 契约仅作预期写入。
- 演示数据一律 `TEST-HBOS-M2-RET-*` 前缀。
- 不做飞书提醒、UOM 换算、国密电子签名。

## 四、视觉方案

### 4.1 设计语言

沿用制药实验室风格：洁净、严谨、信息密度适中、状态语义明确。不使用营销式大图、渐变光斑或娱乐化动效；主操作绿色、警告琥珀色、危险红色、信息蓝色。

### 4.2 Token 与排版

复用 `tokens.scss`：`--primary: #0c7c6a`、`--pass: #1d8a5b`、`--warn: #d1871d`、`--danger: #c24d3f`、`--info: #2b6cb0`、`--ink: #162623`、`--muted: #5f726d`、`--line: #d8e2dd`、`--sidebar: #0d2b28`。中文使用 PingFang SC / Noto Sans SC；批号、数量、时间使用等宽字体。卡片圆角 8px，间距体系 4 / 8 / 12 / 14 / 16 / 22px。

### 4.3 状态语义色

在库/部分使用、已批准/已执行/已完成使用绿色；待处理、待库存确认、各级待审批、待执行使用琥珀色；临期 90 天内使用琥珀色、超期使用红色；已销毁/已转出/已用尽/已驳回/已取消使用灰色；观察异常使用红色；受托方留样/外售产品使用蓝色。均以紧凑 Pill 呈现。

### 4.4 响应式

桌面 >1180px 完整侧栏与多列表格；平板 640–1180px 侧栏收窄、KPI 两列、详情单列；手机 <640px 单列表单、操作按钮收拢、表格横向滚动。

## 五、页面设计方案

### 5.1 留样工作台总览

告警条 + KPI 行 + 双栏面板 + 最近登记表。

- 告警条聚合：临期留样、应观察未观察、销毁超期、审批滞留，点击直达对应页面。
- KPI：在库留样、待处理、临期（30/90 天）、应观察未观察、待审批、销毁超期。
- 「观察计划完整性」面板：按产品展示当年已选 N/3，N<3 常驻提示「可补选」。
- 「审批待办」面板：按当前角色列出使用/处理申请待办。
- 下方「季度到期处理清单」：留样期至 ≤ 季度末且未销毁。
- 数据预期来自 `get_retention_dashboard`；图表仅做到期趋势或类别分布，不在前端自行统计。

### 5.2 留样登记与台账

页头操作 + 统计条 + 筛选栏 + 台账表 + 明细抽屉。

- 操作：新增留样登记、从检验样品创建、打印标签、导出。
- 筛选：类别、状态、临期范围、批号关键字。
- 列：留样编号、样品名称、批号、容器、类别、留样日期、留样量、结存（预占）、可用量、留样期至、观察、状态、操作。
- 明细抽屉：主信息、库存操作流水（日期/类型/变动量/结存/经手人/备注）、审计摘要、状态流转。
- 登记弹窗校验：
  - 选择产品带出 `default_uom`、类别、储存条件、留样规则。
  - 全检量 2 倍自动计算仅在 `full_test_qty_uom == default_uom` 时启用；不一致时禁算并提示人工填写。
  - 全检量 < 1g 按 1g 提示，非硬拦截。
  - `is_liquid=1` 硬拦截；`is_outsource=1` 提示由受托方留样，登记直接落「已转出」。
  - `retention_due_date` 默认自动 = 有效期/复验期 + 3 年，人工修正需原因。
- 从检验样品创建：仅样品类型白名单（原料、成品）、状态白名单（检验完成、已放行）；稳定性样品硬拒绝并提示不属于留样。
- 完整性红线：`current_qty` / `reserved_qty` 只读；`available_qty = current_qty - reserved_qty` 仅展示。

### 5.3 留样产品

筛选栏 + 产品表 + 新增/编辑弹窗。

- 列：产品编码、产品名称、类别、留样数量规则、全检量、默认单位、观察规则、标记、状态、操作。
- 液体·不留样红色标记；受托方留样蓝色标记。
- `default_uom` 为全板块 UOM 唯一权威来源，枚举 g/kg/mg/mL/L/瓶/支/袋/桶/盒/其他。
- 类别选「外售产品」自动置观察规则为「每批观察」；`product_code` 唯一；停用产品不再出现在登记选择列表。

### 5.4 观察任务

N/3 完整性条 + Tabs（计划看板 / 观察记录）+ 右侧录入面板。

- 计划看板列：留样编号、产品、批号、偏移月、计划日期、应观察状态、异常标记、操作。
- 完整性条展示各产品「YYYY 年已选 N/3」，N<3 显示「可补选」，超选尝试由后端拦截并在前端呈现系统消息。
- 观察批选取弹窗：产品、年度、批次、原因三选一（年度观察批 / 外售产品每批 / 其他）；「其他」仅 Manager 可选。
- 观察记录：实际观察日期、外观性状、结果（正常/异常）、异常必填描述、观察人、审核人；保存后系统按全部已审核记录推导 `next_obs_month = max(obs_month) + 12`，不做本地 `+= 12` 回写。
- `obs_month=0` 基线可录入，计划日期 = 留样日期 + 0 月。
- 数据预期来自 `get_observation_plan`、`select_obs_batch`、`record_observation`、`review_observation`。

### 5.5 使用申请

状态 Tabs + 申请列表 + 详情抽屉（审批链 + 库存 + 操作）。

- 创建弹窗：选择留样批次，只读带出结存/可用量；申请量、UOM（只读）、触发场景五选一、原因、申请部门、申请人、日期。
- 列表状态：草稿、待库存确认、待QC批准、待QA批准、待QM批准、已批准、已执行、已驳回、已取消。
- 详情抽屉审批链：申请人 → QC 资源管理员（库存确认+预占）→ QC 负责人 → QA 负责人 → 质量管理负责人。
- 动作按角色矩阵显示：库存确认、QC/QA/QM 批准、取样执行、取消（Manager）。
- SoD：同一用户连续两级签署、申请人自批在前端预拦截并提示，后端仍硬校验。
- 取消逃生口：已批准 → 已取消仅 Manager，原因必填，明确提示释放本单预占并写审计；确认前驳回不释放预占。

### 5.6 处理申请

季度到期清单 + 处理申请列表 + 详情抽屉。

- 创建弹窗：处理类型三选一（销毁 / 续留 / 其他）、数量、UOM、原因、方式、地点、申请人、`qa_manager_required`（默认 5 级）。
- 审批链按开关展示 5 级或 4 级，跳过 QA 负责人时显示「审批层跳过」灰态。
- 销毁分支：批准后显示 deadline（QM 批准 + 3 个月），处理人 + 监督人双签完成。
- 续留分支：填新留样期至，完成后展示旧/新值审计摘要。
- 待执行 → 已取消仅 Manager，原因必填；取消后留样按进入待处理前的状态快照恢复。
- 数据预期来自 `get_disposal_quarterly` 与处理申请全链方法。

# 海滨智能工作平台 · 原型 v0.10

## 根因与修改
上一版仅管理目录筛选接入自定义选择浮层，其他位置仍使用系统原生下拉，因此macOS菜单与管理页不同。本轮将适配器覆盖所有页面与弹窗内的单选select，保留原select作为表单与业务状态来源。

统一44px选项、紫色选中与勾、独立键盘焦点、玻璃菜单、触发器间距与焦点环；全局场景用紧凑尺寸。工作工具条按空间整行换行，避免搜索框被挤窄或选择框局部堆叠。

覆盖上下方向、Home/End、Enter/空格、字母前缀、Esc、Tab/Shift+Tab、外部点击关闭、禁用项跳过、动态禁用、必填/错误属性、label聚焦、变化后焦点恢复、弹窗内焦点约束和视口边界。原生多选和size>1列表框不强行改成单选；当前源未发现这两类实例。

## 盘点范围
全局场景与身份、首页周期、工作应用、设计系统示例；员工/部门/角色/审计/其他应用的筛选、编辑与新增表单；账号验证方式、折叠演示场景、各操作结果与恢复表单。说明折叠、导航菜单与日期/文本输入保留各自语义，不伪装成选择框。

- 最后工作工具条调整后另测3尺寸，均无横溢且菜单在视口内。
- 独立验证工作菜单首尾/字母匹配/提交/取消；全局场景同步；设置抽屉Esc只关菜单、Tab仍留modal；新增员工公司部门联动、重渲染焦点、label/必填；密码验证方式与结果菜单；390工作、部门和登录长场景菜单滚动/外部关闭。
- 全部JS语法检查通过。

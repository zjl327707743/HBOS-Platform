## 2. 安全边界

本轮不会：

- 执行 `docker compose down -v`；
- 删除任何 Docker volume；
- 重建 `frontend` site；
- 删除 / 修改 Attendance 业务数据；
- 接入 Inventory / LIMS Provider；
- 配置飞书 App Secret；
- 创建 Portal DocType；
- 写入业务事实。

安装 Frappe App 会写入 site 的 Installed Applications 元数据，这是本轮唯一预期的平台级持久化变化。

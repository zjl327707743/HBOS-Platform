# LIMS 第二版静态原型

打开 `index.html` 进入设计评审。页面是纯静态原型，数据只保存在当前浏览器会话；刷新会恢复演示数据。

建议按这条路径审核：

1. 今日工作 → 继续检验；
2. 结果录入 → 修改结果值，观察冻结限度提示；
3. 核对并提交（演示）→ 切换复核员 → 复核与批准；
4. 查看受控台账、审计追踪；
5. 从“全部功能”检查报告、标准、留样和稳定性各页签。

顶部“查看身份”用于切换检验员、复核员和质量人员视角；“评审工具”用于查看数据、无数据、加载和错误状态。

原始品牌素材位于 `assets/健康元集团.png`、`assets/海滨公司.png`，实验室场景插画为 `assets/实验室.svg`。

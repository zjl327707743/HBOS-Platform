## 这版解决的审核要求

1. **中文优先**：导航、按钮、状态、空态和错误提示全部采用中文；英文只保留品牌、系统名、标准缩写和必要的仪器方法名。
2. **完整 LIMS 入口**：检验任务、样品登记与台账、检验结果、检验报告（COA）、质量标准、留样（登记/产品/观察/使用/处理）、稳定性（方案/入箱/取样检测/结果趋势/报告有效期/变更与环境设备）、受控台账、审计追踪与全部功能均可从本地前台进入。
3. **检验流程可理解**：首页以“任务分配 → 开展检验 → 提交结果 → 复核 → 批准”进度条为主线；任务卡同时展示样品、批次、项目、截止时间、完成数和下一步。
4. **结果录入符合习惯**：样品上下文、冻结标准、方法、原始记录、仪器编号、结果限度提示和签署链同屏；含量、水分和定性项目按不同方法展示对应输入方式，不把水分或鉴别误画成含量表单。
5. **双品牌合理出现**：海滨公司标识用于工作台入口与样品标签，健康元集团标识位于全局页头右侧；使用原始图片文件，没有重绘或变形。
6. **实验室场景**：使用锥形瓶、色谱仪、样品瓶、条码标签、冻结限度刻度、色谱图示意和稳定性趋势图等低干扰元素辅助识别，不暗示尚未接入的实时仪器监控或预约能力。
7. **响应式与效率**：桌面为侧栏 + 工作区，768px 收敛为堆叠布局，390px 使用全宽状态筛选、单列任务卡、结果录入底部动作栏和台账列表/详情切换；按钮和关键触控区域按 44×44 设计。

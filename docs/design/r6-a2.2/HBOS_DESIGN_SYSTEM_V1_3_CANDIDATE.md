# HBOS 设计规范 v1.3 · 候选增补

状态：R6-A2.2 设计候选，Owner 视觉确认待完成。此文件增补 v1.2，不覆盖或改写 `HBOS_DESIGN_SYSTEM_V1_2.md` 与其历史证据。适用范围为 `design/r6-experience-v2/` 合成数据原型；不构成产品实施或权限变更授权。

## 1. 工作区宽度与对齐

- 桌面管理工作区的可用宽度 = CSS 视口宽度减去垂直管理侧栏宽度。内容容器在可用区中随视口伸缩，桌面内容最大宽度为 **1440 CSS px**；左右保留至少约 24–32px 的工作区内边距，超宽时多余空间居中分配，不无限加长阅读行。
- 1920×1080 与 1728×900 下，部门与角色的双栏内容宽度须分别占侧栏外可用宽度至少约 **70%**；1920 下右侧实际工作面建议 ≥800px。1600px 视口应平滑收缩；2560px 允许因 1440px 最大宽度而低于 70%。
- 面包屑、标题、双栏及页脚使用同一水平边界。纵向 flex 容器中的居中子项同时声明可用宽度与最大宽度；不能只设置 auto 外边距与 max-width，使内容按固有宽度收缩。
- 宽屏下左侧部门/角色导航 240px，列间距 24px，右侧使用 `minmax(0,1fr)`；较窄桌面按现有断点收缩。主内容、网格与面板均需允许收缩而不横向溢出。

## 2. 双栏面板与最小可阅读高度

- 桌面双栏由同一网格行拉伸，两个 `PanelFrame` 外框上下对齐、高度差 ≤1 CSS px；数据少的导航面板也填满。常规高度下标题/必要工具与底部操作固定，中间具名、可聚焦区域负责滚动，不在同一内容区叠加三层纵向滚动。
- 内部工作区的目标可阅读高度不低于 **约 260 CSS px**。窄高窗口不允许为了固定页尾把正文压成一条短缝：当前实现对桌面视口高度 **≤700px** 改为主内容区自然纵向滚动，面板正文不再各自截成短内滚区，双栏仍随内容等高；标题和底部动作随主区滚动并可经滚轮或键盘到达。高度与文字换行、编辑态头部共同影响可读性，新增状态必须复测，不能只依据断点宣称通过。
- 手机 ≤760px 使用单列自然流；部门选择可横向滚动，正文由窗口滚动，焦点与按钮必须可达。真实浏览器放大后按实际 CSS 视口重排；DPR 模拟不是原生缩放测试。

## 3. 个人中心

- 独立于管理中心导航，使用单列主内容，桌面最大宽度 **1160 CSS px**。上部“我的工作身份”呈现姓名、工号、部门、岗位及档案状态；系统内置 Administrator 的 Employee 为“不适用”，待关联员工必须呈现“待核对”。
- 下部“登录与安全”完整保留密码、飞书登录和账号恢复的状态、说明与动作；已绑定、暂未开放和无恢复邮箱不可混为一谈。安全帮助就近写在对应操作项，不用介绍、提示或重复说明卡片占据另一列。
- 原型只展示模拟信息和模拟验证，不输入真实密码，不触发真实 OAuth、绑定或用户管理操作。

## 4. 不退化与验收方法

- 继续复用现有工作台 PointerAtmosphere、三层 aurora 与品牌参数，保留单实例、暂停和 `prefers-reduced-motion` 行为；不得新增更强粒子或新主题。
- 员工表格、部门配置、角色草稿与发布、取消、合成 409/403/5xx/401 恢复、身份和权限语义保持。桌面需测滚轮与键盘，触控板、真实设备与辅助技术按实际测试情况标记，不能从程序断言推断真人体验。
- 每个目标视口记录 CSS 视口 / DPR、侧栏、可用宽度、内容占比、左右面板宽高及高度差、主区和面板滚动高度；1920/1728 的三个指定页面保留修复前后同尺寸单视口原图。Owner 的视觉验收与真人理解测试独立于脚本通过状态。

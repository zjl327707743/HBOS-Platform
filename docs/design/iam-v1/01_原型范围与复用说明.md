# IAM V1 · R3 原型范围与复用说明

日期：2026-10-14。交付状态：`IAM_V1_PROTOTYPE_REVIEW_READY`（仅交互原型）；Owner 审批：`PENDING_OWNER`。本记录不代表正式功能上线或真实运行验收通过。

**执行边界与基线。** 本轮依据 R3《02_唯一执行任务_先做原型.md》及 [Issue #41 的 R3 执行口径](https://github.com/zjl327707743/HBOS-Platform/issues/41#issuecomment-6163623636)，先制作人员、部门、权限及登录流程的可点击原型。独立目录为 `HBOS-IAM-V1`，分支为 `design/iam-v1-prototype-20261014`，基线为 `39366822a5b5d6041b9eea94da4f77255ad26761`。本轮修改白名单仅为 `prototypes/iam-v1/` 与 `docs/design/iam-v1/`；已有成果保留，R2 直接后端开发不执行。

**来源与复用取舍。** 只读参考 [Issue #37](https://github.com/zjl327707743/HBOS-Platform/issues/37) 的固定版本 `a91708d858c9c4c7a06ea999426c29dc2efd4386` 中 `PeopleInformation`、`RoleEditor`、样式、授权与契约说明；同时参考当前基线的 `PortalSidebar`、`AccountSecurity` 与主题 tokens。下表记录复用判断，未复制既有认证 API 或旧 schema。

| 范围 | 保留的设计意图 | 本轮原型调整 | Owner 确认后的实现事项 |
| --- | --- | --- | --- |
| 页面框架与视觉 | 侧栏分区、内容层级、账号安全入口 | Vue 3 + Ant Design Vue；现有 tokens 含蓝紫与玻璃风，本轮依 R3 收敛为浅绿企业视觉，等待 Owner 确认 | 统一产品 tokens 与共享组件，核对整体 Portal 一致性 |
| 人员与账号 | 人员信息、账号状态及管理动作分离 | 合成人员场景；受控开通、调岗、停用、重置、未映射与核验状态可点击 | 对接权威人员来源、唯一账号与状态规则 |
| 部门 | 组织层级、主岗与兼岗信息 | 主岗继承、兼岗不自动叠权；普通预设先预览具名员工与范围差异，再确认本机保存 | 建立受控部门映射、导入核验及变更审计 |
| 权限 | APP、动作、数据范围的授权契约 | 继承 / 额外允许 / 明确禁止；删除例外恢复继承；APP 整体禁止优先；空范围拒绝；高风险具名资格与领域校验 | 在服务端与业务领域执行相同规则，禁止前端绕过 |
| 登录与账号安全 | 同一企业人员对应同一账号，安全状态可解释 | 模拟飞书与密码入口、首次改密、本人找回、换绑、停用及会话失效；不自动注册账号 | 接入真实认证、恢复证明、会话撤销与审计 |
| 模块扩展 | APP 接入依赖统一权限描述 | 设备管理通过合成元数据注册，沿用同一配置界面；仅验证交互契约 | 注册真实业务模块与受控执行器 |

| OAuth、MFA proofs、sessions | `NOT_RUN` / 未接入 | 未接入真实飞书认证、验证证明与会话系统 |
| schema、migrate | `NOT_RUN` | 未变更旧 schema、数据库结构或运行迁移 |

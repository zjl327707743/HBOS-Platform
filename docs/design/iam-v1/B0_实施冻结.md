## 3. 数据字典与原生权限配合

本轮只用三模型与四User状态，不新增员工/账号/密码/角色库、来源映射表或通用规则引擎。固定产品没有等价IAM Policy/Rule真相。

| 模型 | 精确字段 / 默认 / 服务端约束 |
| --- | --- |
| HBOS IAM Policy | subject_type Select(User/Department)，必填；subject_name Dynamic Link(subject_type)，必填；version Int默认1/只读；enabled Check默认1；rules Table→HBOS IAM Rule。唯一(subject_type,subject_name)，创建与更新锁定；无规则不表示允许 |
| HBOS IAM Rule | app_id/operation_id Data必填/注册校验；effect Select allow/deny必填；scope_type Select SELF/DEPARTMENT/COMPANY/WAREHOUSE/LAB_GROUP/KNOWLEDGE_SPACE/EQUIPMENT/ALL；scope_ref Data明确对象；include_descendants Check默认0，首发拒绝扩大；valid_from/until Datetime；qualification_ref Data受控引用。规范化去重；parent/app_id/operation_id查询索引 |
| HBOS IAM Change Event | actor Link User、request_id Data必填唯一、request_hash Data(SHA256)、subject_type/name、operation、before_json/after_json Code(JSON脱敏允许字段)、version Int、result/reason、occurred_at Datetime。服务端只追加、同ID不同actor/内容拒绝；禁止密码/proof/sid/token及业务原始数据 |
| User | hbos_initial_password_pending Check=0；hbos_temporary_password Check=0；hbos_temporary_password_expires_at Datetime；hbos_password_generation Int=0。隐藏/只读/no_copy，仅受控事务写；前两者是状态，不是口令字段 |

Policy/Rule/Event不授普通角色原生写权；控制器拒绝受控上下文之外写入及审计修改，直接REST/子表不能另成授权入口。Role/DocPerm/User Permission只作原生必要约束；IAM管理与已切换业务检查统一读Policy，不能以粗角色作为撤销后的备用许可。普通员工不能通过关联获得HR Manager/System Manager。旧HR能力未迁移时单独保持并回归，不全局关掉旧合法业务。

业务成对规则逐(app,operation,object)求值，应用入口限制与动作范围同时有效，deny只按明确对象生效。ALL只限明确应用停用或受控根委派，不从空/未知值推断。真实首发只开放attendance.read/SELF；attendance.export、部门历史、未接入LIMS/库存/知识/孪生不允许通过本页授予。仓库/多对象示例只在隔离合成域测试，默认关闭。

管理rule按iam.*能力及DEPARTMENT/COMPANY具名目标范围判定；授予内容另查注册域/普通操作/授予范围，拒绝跨目标、自批提权和重要操作混入。审计读取独立。普通员工本人与管理员配置目标不替换session。

停用采用本User/本app的app.enter显式deny行，原工作行保留；启用撤该停用后重算当前部门/期限/资格。恢复普通部门安排只撤本User/本app普通个人行及明确选择的停用，不碰重要/别应用。没有suspendedAppGates新表、任意可写JSON或过期快照回放。

迁移只建三模型、索引及四状态字段；不修改旧账号密码/角色，不猜Employee映射，不导入原件，不重写历史考勤外键。Employee唯一关联通过User/Employee事务锁及原生重复校验，不贸然对现场空串新增唯一索引。

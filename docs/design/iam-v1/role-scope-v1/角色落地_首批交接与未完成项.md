## 模型与事务

精确新增 `HBOS IAM App Role`、`HBOS IAM Role Release`、`HBOS IAM Role Feature`（子表）、`HBOS IAM Role Assignment`、`HBOS IAM Role Scope`（子表）。已有 Change Event 仅增加角色主体类型；无新身份实体、微服务或原生 HR/System Manager 批量映射。角色发布当前 native_mapping_json 固定为空数组；实际有界执行器独立检查当前已发布功能和具名范围。

`api/iam_roles.py` 为显式字段的受控 API；`iam/role_commands.py` 保存草稿、影响预览、原子发布、员工关联、部门默认及历史内容恢复为草稿。草稿与发布版本独立；历史恢复后仍须预览、重新确认发布。发布、范围授予与人员管理是分别授权的 IAM 能力，不从考勤业务角色继承。零引用角色也验证其管理公司域。关联中每一动作与绑定范围成对求值；考勤单选由受控验证实现，物理表不把所有 App 锁死为一个角色。

父行及全部授权子表采用当前锁定读取；预览指纹包含当前发布指针、草稿、直接/继承关联、部门主数据、所有候选成员、用户状态、旧规则活性与操作者版本。取消不写；409 不发布；重试在重新授权后返回已有审计结果。数据库故障注入已验证发布指针、Release 与审计一起回滚。仍须补齐全部成员变动、越权/自提权与迁移回退组合。

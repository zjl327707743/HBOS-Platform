## 六、main 门禁规则

### 门禁类型

由于仓库为 Private 且 GitHub 账户为 Free 计划，GitHub **Rulesets** 和 **Classic Branch Protection** 均不可用（API 返回：`Upgrade to GitHub Pro or make this repository public to enable this feature`）。

**当前状态**：`G1D_A_BRANCH_PROTECTION = BLOCKED_BY_PLAN`

### 已生效的约束

通过仓库级配置实现的约束：

| 规则 | 状态 | 实现方式 |
|------|------|---------|
| 仅允许 Squash Merge | 生效 | 仓库 Settings |
| 关闭 Merge Commit | 生效 | 仓库 Settings |
| 关闭 Rebase Merge | 生效 | 仓库 Settings |
| 合并后自动删除分支 | 生效 | 仓库 Settings |
| PR 要求至少 1 个批准 | **未生效** | 需 Branch Protection |
| 旧批准失效 | **未生效** | 需 Branch Protection |
| 会话解决 | **未生效** | 需 Branch Protection |
| CI 通过门禁 | **未生效** | 需 Branch Protection |
| 禁止 force push | **未生效** | 需 Branch Protection |
| 禁止删除 main | **未生效** | 需 Branch Protection |
| 线性历史 | **未生效** | 需 Branch Protection |

### 缓解措施

在 GitHub Free 计划限制下，通过以下方式实现治理约束：

1. **CONTRIBUTING.md** 明确禁止直接 push main
2. **团队 SOP 第 10 节**规定完整 PR 流程
3. **CI 工作流**在 PR 时自动运行质量检查
4. **Owner 审计**定期检查仓库活动日志
5. **CODEOWNERS** 文件确保关键路径需 Owner 审查

### 升级路径

要启用完整的 Branch Protection 或 Rulesets 需满足以下条件之一：

- 升级到 GitHub Pro（付费）
- 将仓库设为 Public（不推荐，含敏感业务逻辑）

# Issue 模板

将此文件复制到 `.github/ISSUE_TEMPLATE/` 目录即可启用。以下为 HBOS 项目建议模板。

---

## Bug 报告模板

保存为 `.github/ISSUE_TEMPLATE/bug_report.md`：

```markdown
---
name: Bug 报告
about: 报告一个问题
title: '[Bug] '
labels: bug
assignees: ''
---

## 问题描述

<!-- 清楚描述 bug 是什么 -->

## 复现步骤

1.
2.
3.

## 期望行为

## 实际行为

## 截图

## 环境信息

- 操作系统：
- Docker 版本：
- 浏览器：
- 分支/commit：

## 附加信息
```

## 功能请求模板

保存为 `.github/ISSUE_TEMPLATE/feature_request.md`：

```markdown
---
name: 功能请求
about: 建议一个新功能
title: '[Feature] '
labels: enhancement
assignees: ''
---

## 功能描述

<!-- 清楚描述你想要什么功能 -->

## 业务场景

<!-- 这个功能用于什么业务场景 -->

## 期望行为

## 备选方案

<!-- 是否考虑过其他实现方式 -->

## 附加信息
```

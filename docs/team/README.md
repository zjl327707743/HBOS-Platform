# 团队协作文档索引

本目录为新乡海滨智能运营管理平台（HBOS）的团队协作规范文档。所有文档面向没有多人协作经验的团队成员编写。

## 推荐阅读顺序

### 新成员第一天

1. **`01_项目真实结构与代码归属审计.md`** — 了解项目到底是什么、代码在哪里、Docker 和 Git 的关系
2. **`07_新成员入职与本地环境上手手册.md`** — 从零开始搭建本地开发环境
3. **`12_常用Git与Docker命令解释.md`** — 理解每条命令是做什么的，避免误操作

### 日常开发

4. **`03_Git与GitHub多人协作规范.md`** — 分支、提交、PR、审查的全部规则
5. **`10_团队日常开发SOP.md`** — 每天开工到收工的标准流程
6. **`05_开源代码二次开发与升级规范.md`** — 什么能改、什么不能改、为什么

### 环境与部署

7. **`04_Docker开发环境复现手册.md`** — 环境启动、停止、重建、故障排查
8. **`08_版本发布回滚备份与环境管理.md`** — 版本管理、备份恢复、发布流程

### 数据与安全

9. **`06_Frappe自定义内容与数据库迁移规范.md`** — DocType、Fixture、Patch、迁移协作
10. **`09_安全密钥与敏感数据规范.md`** — 什么不能提交、Secret 管理、泄露处理

### 管理与决策

11. **`02_目标仓库架构与迁移方案.md`** — 当前仓库模式的问题与推荐方案
12. **`11_项目治理待办与Owner决策清单.md`** — 需要 Owner 拍板的事项清单

# Local Development Environment Variables

项目名称：新乡海滨智能运营管理平台。

## 目的

本文说明未来本地 Frappe / ERPNext / Docker 最小开发环境需要的环境变量分类。本文只定义分类和占位符，不创建 `.env`，不写真实密钥，不创建 `.gitignore`。

## 使用原则

- 真实密钥不得写入文档。
- 真实 `.env` 文件不得提交到 Git。
- 密码、token、secret key 只写占位符。
- M0-R3 如需创建 `.env`，应同时把 `.env` 加入 `.gitignore`。
- 本轮 M0-R2 不创建 `.env`，不创建 `.gitignore`，除非用户另行明确要求。

## 数据库相关变量

- `DB_HOST=<MARIADB_HOST>`
- `DB_PORT=<MARIADB_PORT>`
- `DB_NAME=<FRAPPE_SITE_DATABASE>`
- `DB_USER=<FRAPPE_DB_USER>`
- `DB_PASSWORD=<FRAPPE_DB_PASSWORD>`
- `MYSQL_ROOT_PASSWORD=<MYSQL_ROOT_PASSWORD>`
- `MYSQL_CHARACTER_SET=<utf8mb4>`
- `MYSQL_COLLATION=<utf8mb4_unicode_ci>`

## Redis 相关变量

- `REDIS_CACHE_HOST=<REDIS_CACHE_HOST>`
- `REDIS_CACHE_PORT=<REDIS_CACHE_PORT>`
- `REDIS_QUEUE_HOST=<REDIS_QUEUE_HOST>`
- `REDIS_QUEUE_PORT=<REDIS_QUEUE_PORT>`
- `REDIS_SOCKETIO_HOST=<REDIS_SOCKETIO_HOST>`
- `REDIS_SOCKETIO_PORT=<REDIS_SOCKETIO_PORT>`

## Frappe Site 相关变量

- `FRAPPE_SITE_NAME=<LOCAL_SITE_NAME>`
- `FRAPPE_SITE_PATH=<LOCAL_SITE_PATH>`
- `FRAPPE_INSTALL_APPS=<erpnext>`
- `FRAPPE_DEVELOPER_MODE=<0_OR_1>`
- `FRAPPE_WORKER_COUNT=<WORKER_COUNT>`
- `FRAPPE_SCHEDULER_ENABLED=<0_OR_1>`

## 管理员账号变量

- `ADMIN_USER=<ADMIN_USER>`
- `ADMIN_PASSWORD=<ADMIN_PASSWORD>`
- `ADMIN_EMAIL=<ADMIN_EMAIL>`

管理员密码必须只放在本地未提交配置中，不得写入仓库文档或示例中的真实值。

## 域名和端口变量

- `LOCAL_SITE_HOST=<LOCAL_SITE_HOST>`
- `HTTP_PORT=<HTTP_PORT>`
- `HTTPS_PORT=<HTTPS_PORT>`
- `FRAPPE_WEB_PORT=<FRAPPE_WEB_PORT>`
- `NGINX_PORT=<NGINX_PORT>`
- `DB_EXPOSED_PORT=<OPTIONAL_DB_EXPOSED_PORT>`

端口值应在 M0-R3 执行前根据本机占用情况确认。

## 密钥变量

- `SECRET_KEY=<SECRET_KEY>`
- `ENCRYPTION_KEY=<ENCRYPTION_KEY>`
- `JWT_SECRET=<JWT_SECRET>`
- `WEBHOOK_SECRET=<WEBHOOK_SECRET>`

以上值均为占位符，不代表真实密钥。真实值只能存放在本地未提交文件或安全密钥管理系统中。

## 后续处理

M0-R3 如进入实际环境落地，应基于本文创建 `.env.example` 或等价示例文件，并单独创建真实 `.env`。真实 `.env` 必须加入 `.gitignore`，但本轮不创建这些文件。

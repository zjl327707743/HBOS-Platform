# HBOS IAM V1 · R3 可点击原型

状态：`IAM_V1_PROTOTYPE_REVIEW_READY`；正式开发批准：`PENDING_OWNER`。

本目录独立于产品构建。Vue 3 + Ant Design Vue；所有人员、账号、部门、联系方式和身份标识均为合成示例。页面始终标示“交互原型 / 合成数据 / 尚未连接 HBOS 后端”。没有 OAuth、认证 API、数据库或 Frappe 代理。

## 本机启动与停止

在本目录运行：

```sh
npm ci
npm start
npm run status
npm stop
```

地址：`http://iam-prototype.localhost:5197/`，备用 `http://127.0.0.1:5197/`。只监听 `127.0.0.1`，未改 hosts。原默认端口 5196 属于已有服务，原型采用 5197。`npm start/stop` 只管理本目录登记且命令来源匹配的 PID；端口冲突时拒绝启动，不停止别人。后台记录与日志仅写入被忽略的 `.runtime/`。

也可运行 `npm run dev`，前台运行后用 Ctrl+C 停止。若 5197 被占用，可前台运行 `npm run dev -- --port 5198`，先核对空闲端口。

## 一条完整评审路径

1. 右上角“切换演示身份”选择演示管理员，进入三页管理。
2. 部门组织 → 调整预设 → 选择 APP / 普通动作 / 范围 → 预览受影响员工 → 确认保存。清空预设范围可观察拒绝；高风险动作不出现在普通预设中。
3. 人员管理 → 新增合成员工，或沈禾详情 → 核验企业人员 → 受控开通。查看一次演示临时密码；关闭后不可再次查看，管理员也看不到员工现用密码。
4. 应用权限 → 选择员工 → APP → 动作 → 个人继承、额外允许、明确禁止与范围。删除个人例外恢复继承；APP 整体禁止覆盖其动作。点击注册演示模块，设备模块按同一界面出现，默认无权。
5. 人员详情 → 调岗 → 观察撤旧授新普通继承、高风险不自动增加、个人例外保留；查看有效权限与变更记录。可演示停用或管理员重置临时密码。
6. 切换沈禾，密码登录先强制演示改密；再进入员工工作台。普通员工只看到本人资料与账号安全，点击无权限应用显示 403。
7. 退出后选择林舟，飞书与密码两条登录路径对应同一账号 `demo.e1@example.invalid` 和相同权限。未开通、未绑定、停用与服务失败有明确提示。
8. 员工账号安全 → 本人改密 / 找回 → 重新验证及 MFA；飞书换绑 → 验证 → 新身份 → 影响 → 结果，选择其他员工占用身份会拒绝。
9. 页面底部“演示工具”模拟加载、加载失败、保存失败、版本冲突、会话过期。保存失败与冲突不生效、不留下成功记录。通过搜索不存在的合成姓名查看空状态。
10. “重置合成演示”恢复初始状态，只作用于本机原型的 `hbos.iam-v1.r3.synthetic.v3` 记录，不修改其他服务。

## 检查

```sh
npm test
npm run build
```

20 项测试仅证明演示契约和状态流；不证明服务器权限、密码安全、SQL 隔离或真实会话撤销。构建保留 Ant Design 全量依赖体积提示，这是本地原型，后续正式界面移植时需按产品构建拆分。

设计、来源核验、Owner 评审单及截图位于 `docs/design/iam-v1/`。Draft PR 只用于评审留档，禁止合并。Owner 批准指定原型 commit 并下达实施指令后，才从当时最新产品分支另建功能分支、选择性移植界面和接入真实后端。

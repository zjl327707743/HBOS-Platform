## 本机使用

```sh
npm ci
npm start
npm run status
npm stop
```

在本目录运行。打开 `http://iam-prototype.localhost:5197/`，备用 `http://127.0.0.1:5197/`。仅绑定回环地址；脚本只管理本目录登记且来源匹配的 PID，不碰5196或其他进程。后台记录写入被忽略的 `.runtime/`。需要重新安装依赖时才运行npm ci。

默认直接显示正常员工管理页，使用明确标注的合成管理员视角。它不是认证或正式管理权限。右上角可进入已有登录演示；登录、首次改密、本人验证、绑定、恢复与停用行为沿用既有流程。

## 直接体验五个日常任务

- 员工行“开通账号”：核对已有员工后开户；不重复新增员工。
- 员工详情“应用使用”：直接看懂可做的工作、对象和来源；考勤示例仅显示自己的记录。
- 库存管理“修改”：每项工作分别选择仓库，结果明确说明可查A仓、不可查B仓和不能办理出库。
- “停用这个应用”：一次确认只影响该员工该应用，原设置保留；恢复和重新启用都先展示将得到的结果。
- 部门管理“默认应用”：普通安排面向本部门员工，考勤仍各看本人；员工详情“调岗”先展示前后安排和保留的个人特别设置。

员工页与应用总览共用单一员工抽屉、WorkSettings和保存命令。部门普通安排复用同一组件。重要操作只读，不能通过普通勾选获得；部门历史查询与考勤导出暂未开放。
